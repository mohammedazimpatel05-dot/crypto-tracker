# 🚀 Live Crypto Tracker Dashboard

A real-time cryptocurrency tracking full-stack web application built entirely on Android using Termux.

## 🛠️ Tech Stack
* **Backend:** Python, Flask, REST API
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Data & Charts:** CoinGecko API, Chart.js

## ✨ Features
* **Real-Time Data:** Live cryptocurrency prices fetched directly via CoinGecko API.
* **Interactive Charts:** Animated line charts powered by Chart.js.
* **Multi-Coin Support:** Seamlessly switch between Bitcoin, Ethereum, and Dogecoin.
* **Auto-Refresh:** Dashboard updates automatically without reloading the page.
